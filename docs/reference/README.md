# Upstream provenance

The 3D world in `src/game/` is adapted from Bruno Simon's public *folio-2025*
project. Its MIT licence notice is kept in [`src/game/license.md`](../../src/game/license.md).
The live CareerCraft frontend is `src/game/sources/`, with runtime assets in
`src/game/static/`.

The archived mirror of the upstream site that was used for comparison during
development is not included in this submission. `src/tools/mirror.py` can
recreate it; it makes external network requests and is not needed to run the game.
